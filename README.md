# Посещаемость кружка робототехники

Сайт учёта посещаемости для кружка МОФ «БІЛІМ-ИННОВАЦИЯ»: журнал занятий,
личный кабинет ученика, итоговый анализ пропусков за год, олимпиады и темы для изучения.

**Открыть:** https://yessenali2001-rgb.github.io/aqtoberobotics/

Данные хранятся в Google-таблице кружка. Сайт — статический (GitHub Pages),
сервером работает скрипт Google Apps Script. Сервер уже подключён: его адрес
прописан в `index.html` (`DEFAULT_API_URL`), вводить ничего не нужно.

## Что умеет

| Роль | Возможности |
|---|---|
| **Администратор** | всё: расписание, каникулы, ученики, сотрудники, удаление данных |
| **Помощник** | отмечать посещаемость, добавлять учеников, олимпиады и темы |
| **Ученик** | видит только свои посещения, пропуски, олимпиады и темы |
| **Родитель** | видит только своего ребёнка: занятия, пропуски, награды, темы и календарь стартов |

- Отметки: **Был**, **Опоздал**, **Уважительная**, **Пропуск**. Для длинных занятий
  можно указать, сколько часов ученик реально был (например, 2 из 4 в субботу).
- У каждого ученика есть класс, команда (Aqsonix, GAMBIT…), категория (FLL / FTC)
  и роль в команде (капитан, билдер, программист, SMM…). Журнал, таблицу и анализ
  можно отфильтровать по команде и категории.
- Вкладка **Достижения**: медальный зачёт кружка — сколько первых, вторых и третьих
  мест, кто лучший, какая команда сильнее, на каких соревнованиях берём больше всего.
  Там же сводка «кто где выступал» (ученики × соревнования) и все записи о наградах.
- Вкладка **Календарь**: соревнования сезона с обратным отсчётом, составом на каждый
  старт и кнопкой «Записать результаты» — она заносит награды сразу всем участникам.
  Рядом — ближайшие дни рождения.
- **Фотографии учеников**: кружок с фото в журнале, списке и карточке; где фото нет —
  инициалы. Снимок уменьшается прямо в браузере до 256 точек и уходит на сервер
  частями. Хранится в таблице и виден только тем, кто вошёл в систему, —
  публичных ссылок на фотографии детей не создаётся.
- **Дни рождения** видны на любой вкладке: в сам день — поздравление с возрастом,
  в остальные — кто ближайший и через сколько дней.
- Вкладка **План и темы**: годовой план по ролям и темы для изучения. Любой пункт
  плана одной кнопкой превращается в тему для ученика, команды, всех с такой ролью
  или для всех сразу.
- Расписание по умолчанию: Пн–Пт по 1 ч, Сб 4 ч, Вс выходной — меняется в настройках.
- Учеников можно добавлять в любой момент: у каждого есть дата зачисления,
  и занятия до неё в его статистику не попадают.
- Проценты считаются только по **проведённым** занятиям (где есть хоть одна отметка),
  поэтому в середине года цифры не занижаются.
- Выгрузка CSV (открывается в Excel): итоги посещаемости, олимпиады, темы.

## Установка — 5 шагов

Понадобится только ваш Google-аккаунт. Всё, что нужно вставить, лежит в одном
файле [`setup-all.gs`](setup-all.gs) — в нём уже и программа, и данные кружка.

1. **Таблица.** Откройте `sheets.new`, назовите таблицу, например,
   «Кружок робототехники — посещаемость».
2. **Скрипт.** Меню **Расширения → Apps Script**. Удалите всё, что в файле `Код.gs`,
   вставьте туда целиком содержимое `setup-all.gs`, нажмите сохранить (дискета).
3. **Запуск.** Вверху в списке функций выберите **`setupAll`** → **Выполнить**.
   Google спросит разрешения — «Дополнительные настройки» → «Перейти к проекту» → «Разрешить».
   Это разрешение для вашего же скрипта в вашей же таблице.
   Появится окно: **код администратора** (запишите его) и итоги импорта.
   Коды всех учеников окажутся на листе **«Коды»** — раздайте их и удалите лист.
4. **Публикация.** **Развернуть → Новое развёртывание → Веб-приложение**:
   «Запуск от имени» — **Я**, «У кого есть доступ» — **У всех** → **Развернуть**.
   Скопируйте ссылку, оканчивающуюся на **`/exec`**.
5. **Сайт.** Включите GitHub Pages: **Settings → Pages → Source: Deploy from a branch →
   ветка `main`, папка `/ (root)` → Save**. Через минуту сайт откроется по адресу
   https://yessenali2001-rgb.github.io/aqtoberobotics/ — входите кодом администратора.

Если вы сделаете **новое** развёртывание Apps Script, адрес `/exec` поменяется.
Тогда либо впишите новый в `index.html` (`DEFAULT_API_URL`), либо нажмите на экране
входа «Изменить адрес сервера».

### Если хочется по отдельности

`setup-all.gs` собирается из двух файлов: [`Code.gs`](Code.gs) (программа) и
[`import-club-data.gs`](import-club-data.gs) (данные кружка). Их можно вставить
двумя файлами и запустить `setup()`, а затем `importClubData()`.
После правки любого из них пересоберите общий файл: `sh build-setup-all.sh`.

## Импорт данных кружка робототехники

В репозитории лежит файл [`import-club-data.gs`](import-club-data.gs) — в нём уже
записаны данные из вашей таблицы `robotics_club.xlsx`:

- **46 учеников**: 29 из состава 26-27 (с классом, командой и категорией FLL/FTC)
  и 17 из прошлогоднего состава — они добавлены **в архив**, чтобы не мешали в журнале,
  но их награды сохранены. Вернуть любого можно кнопкой «Вернуть» на вкладке «Ученики».
- **140 записей о наградах** по 9 соревнованиям (First Aqtobe Regional, Bishkek,
  Batys Mangistau, Fibonacci Astana, Astana CAFC, INFOMATRIX, Fibonacci Turkey,
  FLL Bulgaria, WRO) — с уровнем и результатом, исходная формулировка сохранена в примечании.
- **16 соревнований** сезона 26-27 в календарь.
- **93 пункта годового плана** по ролям (Captain, Manager, Builder, Programmer, SMM, Slider).

Если вы ставили систему по инструкции выше, импорт уже выполнен функцией `setupAll`.
Запустить его отдельно можно функцией **`importClubData`** — повторный запуск
безопасен, дубликатов не будет.

> **ИИН, даты рождения и номера документов из таблицы НЕ переносились** — этим данным
> не место в веб-приложении, для учёта посещаемости они не нужны. Они остаются
> в вашем исходном файле.

Даты у импортированных наград пустые (в таблице их не было) — при желании
проставьте их в карточке ученика.

Даты рождения переносятся отдельно: функция **`importBirthdays`** в Apps Script
(20 дат из листа «Оқушылар дата»). Имена сверяются без учёта ә/ғ/қ/ң/ө/ұ/ү/і,
поэтому «Амангос» и «Аманғос» считаются одним человеком.

## Обновление кода

Если вы правите `Code.gs`, после сохранения нужно выпустить новую версию:
**Развернуть → Управление развёртываниями → карандаш → Версия: Новая → Развернуть**.
Ссылка `/exec` при этом не меняется.

## Частые вопросы

**Ученик забыл код.** Вкладка «Ученики» → «Новый код». Старый перестанет работать.

**Ученик ушёл из кружка.** Кнопка «В архив» — он пропадёт из журнала,
но его статистика и достижения сохранятся для годового отчёта.

**Занятие не состоялось.** Добавьте дату в «Каникулы и дни без занятий» —
этот день исчезнет из плана и никому не будет засчитан как пропуск.

**Можно ли работать без интернета?** Просмотр — да (последняя загруженная
страница кэшируется), отметки — нет, для них нужна связь с таблицей.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | всё приложение: интерфейс и логика |
| `setup-all.gs` | **то, что вставляют в Apps Script**: программа + данные кружка |
| `Code.gs` | серверная часть (исходник) |
| `import-club-data.gs` | разовый импорт состава, наград, календаря и плана |

| `manifest.json`, `sw.js` | установка на телефон как приложение |
